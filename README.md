Mario-style Platformer Game
A 2D platformer game built with Kaboom.js. Navigate through multiple levels, collect coins, avoid enemies, and unlock power-ups. Classic platformer mechanics with responsive design and smooth gameplay.

Features
Multiple levels with increasing difficulty

Collect coins and power-ups

Enemies to avoid or defeat

Smooth character movement and jumping mechanics

Customizable levels and sprites

How to Play
Use the arrow keys to move left and right.

Press space to jump.

Press down near pipes to enter them.

Collect coins and avoid or defeat enemies.
